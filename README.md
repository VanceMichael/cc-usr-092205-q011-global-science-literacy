# 国际科普合作项目账

跟踪世界公众科学素质组织联合项目的承诺、交付与影响。该组织有来自五大洲21个国家的32家创始单位会员，联合项目使用不同工作语言、面向不同受众、适用不同数据规则；本台账保证会议意向不被误记为交付成果。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例（全部人名、机构名为虚构）。读取模块统一加载这些资料，先做结构校验，再执行业务不变量检查。

每个提案（`proposals`）从**资源承诺**开始（谁、承诺什么资源、何时承诺），随后依次记录：

- 预算（金额、币种、出资方与比例，比例之和须为 1）
- 翻译版本（语言、版本号、发布日期）
- 活动范围与受众定义
- 开放材料（许可与语言版本）
- 当地反馈与持续行动
- 尚未完成的依赖与可获得的协作
- 谱系（`lineage`）：项目拆分、成员退出、负责人变化、跨年度续作均登记事件，并保留可追溯的责任链（原始责任方 → 当前承担方）

业务不变量（由 `src/domain.py` 强制）：

1. 同一场活动（按 `dedup_key` 识别）被多家会员报送，秘书处只确认一次
2. 敏感参与者数据必须留在来源国，存储国与来源国一致，不得跨境
3. 公开数字必须注明覆盖范围；未确认活动不得发布数字
4. 与项目存在利益冲突的评审人不得参与资助评审和成果验收
5. 标记为“产生后续影响”或已确认的活动必须附当地证据；合影、新闻稿不能替代当地证据
6. 已退出会员不能继续担任负责人，但其原有责任记录保留可查

## 汇总视图

- `member_homepage(data, member_id)`：会员首页，展示该会员尚未完成的依赖和可获得的协作
- `secretariat_summary(data)`：秘书处按**意向 / 在办 / 完成 / 产生后续影响**四种事实汇总，并分别给出已确认活动数（去重后）与原始报送次数

样例覆盖三种典型情形：P-01 在办项目（多语言、敏感数据留肯尼亚、重复报送被拒）、P-02 跨年度续作且已产生后续影响（负责人变更、会员退出）、P-03 由 P-01 拆分出的意向项目。

## 本地校验

```bash
python -m unittest discover -s tests
```

19 项测试覆盖承诺起点、预算比例、活动去重、证据要求、数据驻留、利益冲突、责任链与两种汇总视图。仓库不保存账号、密钥、连接串或真实身份资料。
