# 国际科普合作项目账

跟踪国际公众科学素质合作项目的承诺、交付与影响。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例。`src/domain.py` 统一加载这些资料，校验必要字段与跨字段约束，并提供会员首页与秘书处汇总两个派生视图。

当前资料反映以下领域事实：

- 该组织已有来自五大洲21个国家的32家创始单位会员
- 组织目标包括推动交流合作与协同创新
- 合作希望促进科技与社会良性互动并提升公众科学素质
- 联合项目的工作语言、受众定义与数据规则因会员而异

## 记账规则

1. 提案以承诺为起点：先记录谁承诺提供什么资源，再记录预算、翻译版本、活动范围、开放材料、当地反馈与持续行动。
2. 项目拆分、成员退出、负责人变化或跨年度续作时，通过事件留痕与来源提案关联，原有承诺与责任人仍可辨认。
3. 同一活动被多家会员报送时按去重键只确认一次；确认必须依据当地证据，合影或新闻稿不能替代。
4. 敏感参与者数据留在来源国；公开数字注明覆盖范围。
5. 存在利益冲突的评审人不得参与资助和验收。

## 派生视图

- `member_homepage(domain, member_id)`：会员首页，列出本人尚未完成的依赖（未兑现承诺与未完成的持续行动）和可获得的协作（本人尚未参与的意向或在办提案）。
- `secretariat_summary(domain)`：秘书处汇总，按意向、在办、完成、产生后续影响四种事实统计提案，并按去重键统计已确认活动，不以报送次数或参与机构数充数。

## 本地校验

运行 `python -m unittest` 可确认样例资料符合约定。仓库不保存账号、密钥、连接串或真实身份资料。
